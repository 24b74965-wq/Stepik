Как зарегистрироваться на GitHub

GitHub — это крупнейшая платформа для хостинга IT-проектов и совместной разработки. Данный гид поможет вам быстро создать аккаунт.

Шаги для создания аккаунта

Шаг 1

Перейдите на сайт github.com и нажмите кнопку Sign up.

Шаг 2

Введите ваш email, создайте надежный пароль и придумайте уникальный username.

Шаг 3

Пройдите простую капчу и подтвердите вашу электронную почту с помощью кода.
